Simpan Data Pelanggan ke VS Code & Netlify

Jadikan data yang Anda isi di panel ini 100% permanen di kodingan VS Code agar langsung tampil di Netlify untuk semua tamu!

Kenapa harus disimpan ke VS Code sebelum ke Netlify?

Tombol "Simpan Semua Perubahan" di bawah menyimpan data ke memori browser laptop Anda. Agar tamu yang membuka web di Netlify dari HP mereka melihat data pelanggan ini, Anda cukup klik "Download wedding-data.js" lalu timpa/ganti file wedding-data.js di folder VS Code Anda, lalu deploy ke Netlify!
